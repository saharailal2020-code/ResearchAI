# UI-002 Activity Timeline

Status:
Backlog

## Judul

Activity Timeline

## Tujuan

Menampilkan activity lintas modul yang relevan dengan client atau proposal.

## Deskripsi

Activity Timeline adalah bagian dari cross-cutting behavior ResearchAI. Setiap modul bisnis yang dibangun perlu mencatat aktivitas penting ke timeline.

Untuk Proposal, activity yang relevan antara lain:

- Proposal dibuat.
- Proposal diperbarui.
- Proposal dikirim ke client.
- Proposal perlu revisi.
- Proposal disetujui.
- Proposal ditolak.

## Acceptance Criteria

- Activity Timeline dapat menampilkan activity dari backend.
- Activity berisi judul, deskripsi, tipe, tanggal, dan sumber.
- Activity dapat dikaitkan dengan Client 360.
- Activity dapat dikaitkan dengan Proposal Detail jika diperlukan.

## Catatan

Tidak dikerjakan pada Sprint 3.
