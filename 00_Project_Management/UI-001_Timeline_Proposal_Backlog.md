# UI-001 Timeline Proposal

Status:
Backlog

## Judul

Timeline Proposal

## Tujuan

Menampilkan riwayat lifecycle satu proposal secara ringkas di halaman Proposal Detail.

## Deskripsi

Timeline Proposal akan membantu user melihat perjalanan proposal dari Draft sampai Approved atau Rejected.

Contoh event:

- Proposal dibuat.
- Proposal dikirim ke client.
- Proposal perlu revisi.
- Proposal disetujui.
- Proposal ditolak.

## Acceptance Criteria

- Timeline tampil di Proposal Detail.
- Timeline hanya menampilkan event terkait proposal tersebut.
- Event diurutkan dari terbaru ke terlama atau sesuai keputusan desain.
- Event menampilkan tanggal, judul aktivitas, dan deskripsi singkat.

## Catatan

Tidak dikerjakan pada Sprint 3.
